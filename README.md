PHP Admin API
REST API и админ-панель для управления пользователями

🚀 Установка и запуск
1️⃣ Клонировать репозиторий
bash
git clone https://github.com/leonard-mittemeier/php-admin-api.git
cd php-admin-api
2️⃣ Настроить базу данных MySQL
Создайте новую базу данных

Импортируйте структуру из файла database/schema.sql (если есть)

Настройте параметры подключения в config/database.php или в переменных окружения

3️⃣ Настроить веб-сервер
Для локальной разработки используйте встроенный PHP-сервер:

bash
php -S localhost:8000
Или настройте виртуальный хост для Apache/Nginx, указав корневую директорию public/

4️⃣ Настройка окружения
Скопируйте .env.example в .env и заполните параметры

Установите зависимости через Composer:

bash
composer install
🔧 Конфигурация
Основные настройки находятся в файлах:

config/database.php — подключение к MySQL

config/auth.php — настройки аутентификации

.env — переменные окружения

📡 API Эндпоинты
Метод	Эндпоинт	Описание	Доступ
GET	/api/users	Получить всех пользователей	Админ
GET	/api/users/{id}	Получить пользователя по ID	Админ
POST	/api/users	Создать нового пользователя	Админ
PUT	/api/users/{id}	Обновить пользователя	Админ
DELETE	/api/users/{id}	Удалить пользователя	Админ
POST	/api/auth/login	Вход в систему	Публичный
POST	/api/auth/logout	Выход из системы	Авторизованный
🧪 Тестирование
Для тестирования API используйте Postman или curl.

Пример запроса на создание пользователя:

bash
curl -X POST http://localhost:8000/api/users \
  -H "Content-Type: application/json" \
  -d '{"name": "Иван Иванов", "email": "ivan@example.com", "password": "secret"}'
