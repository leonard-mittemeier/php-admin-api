## 📌 Описание проекта

Полноценное веб-приложение для управления пользователями (CRUD) с REST API и административной панелью. Разработано на чистом PHP без фреймворков для демонстрации глубокого понимания архитектуры веб-приложений, безопасности и работы с базами данных.

Проект создан с использованием подхода **Vibe Coding** — AI-ассистированной разработки, где 60% кода было сгенерировано с помощью ChatGPT и Copilot, а затем проверено, доработано и оптимизировано вручную.

---

## 🚀 Основные возможности

- 🔐 **Авторизация и аутентификация** — регистрация, вход, хэширование паролей, защита маршрутов
- 👥 **Управление пользователями (CRUD)** — создание, просмотр, редактирование, удаление
- ⚙️ **Административная панель** — удобный интерфейс с метриками
- 📡 **REST API** — JSON-эндпоинты для интеграции с внешними системами
- 🗄️ **База данных MySQL** — оптимизированная структура таблиц

## 🚀 Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/leonard-mittemeier/php-admin-api.git
cd php-admin-api
2. Настроить базу данных MySQL
Создайте новую базу данных

Настройте параметры подключения в config/database.php

Импортируйте структуру из database/schema.sql

3. Запустить встроенный PHP-сервер (для разработки)
bash
php -S localhost:8000
Или настройте виртуальный хост для Apache/Nginx, указав корневую директорию public/

4. Установить зависимости
bash
composer install
📡 API Эндпоинты
Метод	Эндпоинт	Описание	Доступ
GET	/api/users	Получить всех пользователей	Админ
GET	/api/users/{id}	Получить пользователя по ID	Админ
POST	/api/users	Создать нового пользователя	Админ
PUT	/api/users/{id}	Обновить пользователя	Админ
DELETE	/api/users/{id}	Удалить пользователя	Админ
POST	/api/auth/login	Вход в систему	Публичный
POST	/api/auth/logout	Выход из системы	Авторизованный
🧪 Тестирование API
Пример запроса на создание пользователя через curl:

bash
curl -X POST http://localhost:8000/api/users \
  -H "Content-Type: application/json" \
  -d '{"name": "Иван Иванов", "email": "ivan@example.com", "password": "secret"}'
